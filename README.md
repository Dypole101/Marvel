# NewyorkCity

A single-file 3D browser game (Three.js) set in a mini New York city. Play as a Sorcerer, an Inventor in armor, or a Thunder God.

## Play
- Open `index.html` in any modern browser, or host it with GitHub Pages.
- Needs an internet connection once, to load Three.js from cdnjs.

## Host on GitHub Pages
1. Create a new repository and upload `index.html` and `README.md`.
2. Go to Settings > Pages, choose the `main` branch and the `/ (root)` folder, then Save.
3. Your game will be at `https://<your-name>.github.io/<repo-name>/`.

## Controls
**Touch:** left side drag = move, right side drag = look. Buttons: USE (fire selected power), NEXT (change power), JUMP, FLY, SPRINT (toggle), SHIELD (hold), plus PORTAL (Sorcerer) and HAMMER (Thunder God).

**PC:** W A S D move, mouse drag look, Space jump, C sprint, G fly, Q shield (hold), F use power, X next power, 1-7 pick a power, E portal, M mirror, T time, R rewind (hold), V hammer, H info.

## Heroes
- **Sorcerer:** portals (tap ground, roofs or walls; save positions), Mirror Dimension (move buildings and floor areas), Time Stone, Rewind.
- **Inventor:** Striker and Nano armor, repulsor, homing rockets, laser, energy shield, helmet HUD with AEGIS voice.
- **Thunder God:** hammer throw and recall, chain lightning, storm strikes, hammer strike, shield.

Choose a hero by standing on a glowing circle inside the tower. The in-game INFO button has the full guide.
